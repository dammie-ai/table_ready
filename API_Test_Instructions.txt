HOW TO USE:
1. Open Postman, import "TableReady API.postman_collection.json"
2. Create a new environment with variables: base_url, manager_token, waiter_token, kitchen_token, delivery_token, order_id, cart_id, menu_item_id, table_id, reservation_id, entry_id, modifier_id, config_id
3. Set base_url = http://localhost:8001/api
4. Run these requests FIRST (in order):
    - "login as manager" → auto-saves manager_token
    - "login as waiter" → auto-saves waiter_token
    - "login as kitchen" → auto-saves kitchen_token
    - "login as delivery" → auto-saves delivery_token
   (Check Postman Console to confirm tokens saved)
5. Test remaining endpoints in order
6. Record results below

TOKEN TROUBLESHOOTING:
- If you get "Security token missing": Run login requests first
- If login fails: Ensure server is running and test users exist
- Tokens expire after 8 hours: Re-run login requests
- Check Postman Console (View → Show Postman Console) for debug logs

END-TO-END TEST RUNNER (Postman Collection Runner):
1. Click the 3 dots on the collection → "Run collection"
2. Select your environment
3. Click "Run TableReady API"
4. After run completes: Click "Export Results" → saves as CSV
5. Open CSV in Excel

END-TO-END TEST RUNNER (Newman CLI):
1. Install: npm install -g newman
2. Run: newman run TableReady\ API.postman_collection.json -e your_env.json -- reporters cli,json,html
3. Open the generated HTML report in browser
